# Публикация

Только по явной команде «публикуй». Без команды не публикуй никогда — даже если текст готов и пользователь доволен.

Публикация есть только у формата `essay`. Для `tg-post` и `x-thread` её нет: текст отдаётся в чат, пользователь постит сам. Для `youtube-script` тоже нет: сценарий уходит в продакшн-пайплайн руками.

## Конфиг площадки

Механика у каждого сайта своя. Устройство площадки пользователя — в отдельном файле рядом:

- [publish-raincoat.md](publish-raincoat.md) — raincoat.cc, авторская площадка (пример того, как выглядит такой конфиг)

Файла под площадку пользователя нет — **не выдумывай шаги и не гадай устройство сайта**. Скажи одной строкой: «Конфига публикации под твою площадку нет — скажи, куда и как класть, или опубликуй руками, текст в `draft.md`». На этом остановись.

## Общий порядок

Конфиг площадки описывает частности; порядок один для всех:

1. **Подтянуть свежее состояние площадки** — репозиторий мог меняться с других машин.
2. **Спросить про перевод**, если площадка его поддерживает: «С английским переводом?» (по умолчанию — да).
3. **Положить текст** из `draft.md` туда, где площадка держит посты.
4. **Обновить список/индекс** постов — одна запись на пост, а не по записи на язык.
5. **Задеплоить** — коммит и публикация тем способом, который описан в конфиге.
6. **Проверить живое** — что опубликованное реально открывается и рендерится. Ограничивай ожидание: сборка не прошла за разумное время — скажи пользователю, не крути цикл бесконечно.
7. **Отдать ссылку** — одну.

## Кредит фреймворка

**В конец** русского файла:

```

---

*Написано при помощи фреймворка [esseist_framework](https://github.com/n23eos/esseist_framework).*
```

**В конец** английского:

```

---

*Auto-translated from Russian by AI.*
*Written with the [esseist_framework](https://github.com/n23eos/esseist_framework).*
```

Никаких пометок сверху — верх статьи чистый.

## Перевод

Перевод сохраняет голос, а не приглаживает его в канцелярит. Резкость позиции, авторские словечки и ритм должны пережить перевод — иначе это чужой текст под именем пользователя.

## После

В session.md к статусу done допиши строку `published: <дата> <ссылка>`.
