# Публикация эссе на raincoat.cc

Только по явной команде «публикуй». Механика проверена 2026-08-30 на эссе «Инструмент всех инструментов».

**Это пример под конкретный сайт, а не универсальный шаг.** Устройство блога, пути и репозиторий ниже — авторские. Ставишь скилл себе — перепиши файл под свою публикацию целиком; общего в нём только порядок: проверить исходники → положить текст → обновить список → задеплоить → убедиться, что живое. Публикуешь руками — скажи пользователю и не выдумывай шаги.

## Устройство сайта

Репо `n23eos/raincoat_website`, GitHub Pages, ветка `master`, домен raincoat.cc. Локальный клон: `~/code_projects/raincoat_website` (нет — склонировать). Блог клиентский: `blog.html` рендерит `posts/<slug>.md`, список — `posts/index.json`. **Один пост = одна запись в списке**; английская версия — файл `posts/<slug>.en.md` + поля `en: true, title_en, desc_en` в записи index.json, переключается штатным RU/EN-свитчем сайта.

## Шаги

1. `git -C ~/code_projects/raincoat_website pull` — сайт мог меняться с других машин.
2. Спроси одной строкой: «С английским переводом?» (по умолчанию — да).
3. Скопируй `draft.md` → `posts/<slug>.md`. **В конец** файла добавь:
   ```
   ---

   *Написано при помощи фреймворка [esseist_framework](https://github.com/n23eos/esseist_framework).*
   ```
4. Если перевод: создай `posts/<slug>.en.md` — перевод, сохраняющий голос (не гладкий канцелярит). **В конец**:
   ```
   ---

   *Auto-translated from Russian by AI.*
   *Written with the [esseist_framework](https://github.com/n23eos/esseist_framework).*
   ```
   Никаких пометок сверху — верх статьи чистый.
5. Добавь **одну** запись в `posts/index.json`: `slug, date, title, desc`; при переводе плюс `en: true, title_en, desc_en`. Отдельную запись для EN не создавать. Проверь JSON валидность.
6. Учти мини-рендерер сайта: заголовки `#`–`###`, списки, цитаты, `**`/`*`/`` ` ``, картинки, `---`. Таблиц и сносок нет — не использовать.
7. Коммит `feat: add essay '<название>' (ru/en)` (без attribution), push в `master`.
8. Проверь живой деплой: `curl -sf https://raincoat.cc/posts/<slug>.md` в until-цикле с ограничением (Pages собирается ~1 минуту; не более ~5 минут ожидания — дальше не крути цикл, скажи пользователю что сборка не прошла и дай ссылку на Actions), затем открой `https://raincoat.cc/blog.html?post=<slug>` в браузере: рендер, футер-кредит, переключение RU/EN (если есть перевод). Учти кеш CDN у blog.html (~10 мин) — при проверке добавляй `&v=N` к URL.
9. Отдай пользователю ссылку (одну — язык переключается на странице).
