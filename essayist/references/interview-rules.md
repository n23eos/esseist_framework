# Правила интервью (СДВГ-специфика)

## Формат порции

```
### Порция 2 из 3 · вопросы 5–8 из 12

5. <вопрос одной строкой>
6. <вопрос>
7. <вопрос>
8. <вопрос>

(«скип» — пропустить вопрос, «стоп» — сохранить и выйти, «сшивай» — собрать статью из того, что есть)
```

Подсказку про команды показывай в первых двух порциях, дальше убирай — она уже выучена, а лишний текст = шум.

## Почему именно так

- **3–5 вопросов, не больше.** Рабочая память при СДВГ короткая: длинный список читается по диагонали, отвечается на первый и последний. Меньше вопросов = все получают ответ.
- **Прогресс-бар обязателен.** «Сколько ещё осталось» — главный источник тревоги. Видимый конец («вопросы 5–8 из 12») удерживает в процессе.
- **Дофаминовая обратная связь.** После каждой порции — одна короткая живая реакция на содержание («История с дедлайном — огонь, это будет вступление»), потом следующая порция. Не хвали пустым «отлично!», реагируй на суть. Но не разворачивай дискуссию — реакция в одну строку, дальше вопросы.
- **Никакого стыда за формат.** Ответ «ну хз, бесит и всё» — валидный ответ, записывай как есть. Просьба «развернуть мысль» = скрытый упрёк = пользователь ушёл.

## Обработка ответов

- Записывай в session.md **дословно**, сразу после получения, до отправки следующей порции. Не перефразируй, не сокращай, не чисти мат — при сшивке живая лексика важнее аккуратности.
- Пользователь ответил на часть вопросов порции — нормально. Неотвеченные помечай `[skipped]` и не возвращайся к ним, если он сам не вернётся.
- Ответ зацепил новую сильную тему — можно добавить 1 вопрос в карту (обнови карту в session.md, скорректируй счётчик). Больше одного — нельзя: расползание карты = интервью без конца.
- Пользователь ушёл в сторону и прислал поток мыслей не по вопросу — это тоже материал. Сохрани в session.md в раздел ответов с пометкой `[поток]`, поблагодари, верни к порции одной строкой.

## Команды

| Команда | Действие |
|---|---|
| «скип» | Пометить текущий/названный вопрос `[skipped]`, продолжить |
| «стоп» | Дописать session.md, подтвердить сохранение одной строкой («Сохранил, 7/12. Вернёмся — скажи "продолжим эссе"»), закончить ход |
| «сшивай» | Пометить остаток карты `[cut]`, перейти к фазе 4 немедленно, без уговоров «может ещё пару вопросов» |
| «в копилку …» | Дописать тему в `<base>/_ideas.md`, подтвердить одной строкой, вернуться к текущей порции |

Распознавай команды по смыслу, не по точному слову: «давай дальше без этого» = скип, «надоело, собирай» = сшивай.
