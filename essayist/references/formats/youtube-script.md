# Формат: youtube-script (сценарий видео)

Дельты поверх базового цикла. Всё, что здесь не переопределено, работает как для эссе.

## Мета-вопросы (фаза 1)

1. Для кого видео? Один типовой зритель.
2. Одна мысль, с которой зритель должен уйти?
3. Длительность? (шортс до 60 сек / короткое 3–5 мин / длинное 10+)
4. Что зритель должен сделать в конце? (подписаться, посмотреть следующее, задуматься — CTA)
5. Какая у тебя энергия по теме одним словом? (азарт, злость, спокойный разбор)

## Карта вопросов (фаза 2)

Размер: шортс — 4–6 вопросов (1–2 порции), обычное видео — 9–15 как у эссе. Дополнительная обязательная зона — **хук**:

- «Какая фраза или факт из этой темы заставит человека НЕ свайпнуть в первые 5 секунд?»
- Для длинных видео добавь 1–2 вопроса про визуал: «Что показать на экране, когда говоришь про X?» — ответы идут в ремарки.

## Сшивка (фаза 4)

- Текст под озвучку: числа прописью («десять тысяч», не «10 000»), предложения короче, чем в эссе, никаких скобочных вставок — их не прочитаешь голосом.
- Хук — первые две фразы, без «привет, сегодня поговорим о». Сразу мясо или интрига из ответа про хук.
- Структура: ХУК → сетап (почему это важно зрителю) → блоки → пейофф (мысль на вынос) → CTA одной фразой.
- Ремарки в квадратных скобках отдельными строками: `[пауза]`, `[на экране: …]` — только там, где ответы пользователя дали материал для визуала.
- Объём: шортс ≈ 150 слов ≈ 60 сек; обычный темп речи ≈ 130–150 слов/мин — считай от длительности из меты и сверяй `wc -w`.
- Outline перед черновиком нужен только для видео 10+ минут; короче — сразу черновик.
- Стиль: у `nikolai-voice` есть режим «Сценарий видео» — применяй его.

## Выдача

`draft.md`: сценарий с ремарками. В чате — целиком. Публикации нет: сценарий уходит в продакшн-пайплайн пользователя руками.
