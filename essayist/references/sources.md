# Источник-инжест

Многие темы в копилке приходят с полем «источник» — заметкой или папкой черновиков, где мысль уже наполовину сформулирована. Интервьюировать такую тему с нуля — заставлять пользователя печатать то, что он уже написал. Этого не делаем.

## Карта волтов

Алиасы путей (RC, CC и т.п.) расшифровываются в `style/sources-map.md` — личный файл, в репо его нет. Если алиас не расшифровывается или файла-карты нет — скажи пользователю и веди обычное интервью без источника.

## Порядок

1. **Перед фазой 1** прочитай источник целиком (папку — все файлы в ней). Источник не найден по пути — скажи одной строкой и продолжай без него, не гадай.
2. **Извлеки из источника** и запиши в session.md в раздел ответов с пометкой `[источник]`:
   - тезисы и формулировки автора (дословно — это его лексика, она пойдёт в текст);
   - примеры, случаи, цифры;
   - готовые куски, если источник — черновик сценария.
3. **Мета-вопросы фазы 1** задавай как обычно, но если источник отвечает на часть из них (например, тон очевиден из заметки) — предложи ответ сам: «судя по заметке, тон — спокойный разбор; так?»
4. **Карту вопросов фазы 2 стройся на дырах.** Сначала покажи пользователю выжимку одной короткой порцией: «Из заметки беру: [3–5 тезисов по строке]. Что выкинуть/поправить?» Это считается порцией 1. Дальше спрашивай ТОЛЬКО то, чего в источнике нет — обычно это:
   - личный случай/история (в заметках часто голый тезис);
   - самый сильный контраргумент и ответ на него;
   - что цепляет именно сейчас (заметка могла лежать годами — отношение менялось);
   - вывод/действие для читателя.
   Карта сжимается: для эссе с жирным источником — 5–8 вопросов вместо 9–15, для поста — 2–3.
5. **Подтверждение вместо печатания.** Где можно, формулируй вопрос так, чтобы ответом было «да / нет / поправка одной фразой», а не абзац. Пользователь печатает меньше — конвейер живее.

## Границы

- Тезисы из источника — материал автора, их можно брать в текст как ответы. Но приоритет у свежих ответов интервью: если ответ противоречит старой заметке, прав ответ.
- Источник другого автора (цитата, статья) — материалом НЕ является, только поводом для вопроса.
- В волты ничего не писать. Только чтение.
