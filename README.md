# esseist_framework

Интервью-конвейер для написания эссе и статей-рассуждений — сделан для людей с СДВГ, которым трудно написать текст «от А до Я» за один присест.

**Идея:** ты даёшь тему → Claude ведёт интервью малыми порциями простых вопросов (3–5 за раз) → из твоих ответов сшивается цельная статья в твоём авторском стиле. Всё состояние живёт в файлах: можно бросить на середине и вернуться через неделю — конвейер поднимет всё с места остановки.

*An interview pipeline for writing essays, built for people with ADHD: you give a topic, Claude interviews you in small batches of simple questions (3–5 at a time), then stitches your answers into a full essay in your own voice. All state lives in files — drop it mid-way, resume a week later.*

## Как это работает

1. **Setup** — тема + 4 мета-вопроса: для кого, главная мысль, площадка/объём, твоё отношение к теме.
2. **Интервью** — карта из 9–15 вопросов, подаётся порциями по 3–5 с прогресс-баром («вопросы 5–8 из 12»). Каждый вопрос отвечается 1–3 предложениями с телефона, хоть голосовым. Команды: «скип», «стоп», «сшивай».
3. **Добивка** — максимум одна порция уточняющих вопросов по тонким местам (опционально).
4. **Сшивка** — outline на согласование → черновик в твоём стиле → анти-слоп проход. Жёсткое правило: факты, мнения и примеры — только из твоих ответов, ничего не досочиняется.

Каждое эссе — папка `essays/<slug>/` с `session.md` (все вопросы-ответы, статус) и `draft.md` (готовая статья).

## Установка

Это скилл для [Claude Code](https://claude.com/claude-code):

```bash
cp -r essayist ~/.claude/skills/
```

Дальше в любой папке: «давай эссе про X» — скилл подхватится сам. Незаконченное эссе поднимается словами «продолжим эссе».

## Свой стиль

Вставь описание своего авторского голоса (лексика, ритм, запрещённые обороты, примеры фраз) в `essayist/style/blueprint.md` ниже разделительной линии — он станет приоритетным источником стиля при сшивке. Без него скилл ищет у тебя стилевой скилл (по умолчанию — `nikolai-voice`, замени в `SKILL.md` на свой) или пишет нейтральным живым языком.

## Структура

```
essayist/
├── SKILL.md                      # оркестратор: фазы, команды, протокол resume
├── references/
│   ├── question-craft.md         # как генерировать вопросы (6 зон покрытия, плохие → хорошие)
│   ├── interview-rules.md        # СДВГ-правила интервью: порции, прогресс, обработка ответов
│   └── synthesis.md              # правила сшивки: границы дозволенного, outline, анти-слоп
├── assets/
│   └── session-template.md       # шаблон файла состояния эссе
└── style/
    └── blueprint.md              # слот под твой стиль
```
