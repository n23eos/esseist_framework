# Eval-петля голоса: протокол L1/L2/L3

Замена сломанного бенчмарка nikolai-voice (N=6, судья = генератор, рубрика = пересказ
запретов самого скилла, человеческие метки инвертируют автооценку — разбор в
`research/2026-09-01-writing-library-research.md` §5).

## Три слоя

**L1 — гардрейлы** (программно, только гейт, не оценка): `l1_guardrails.py`.
Восклицания, эмодзи, буллеты, запрещённые фразы, копипаст-артефакты, лимиты формата.
L1 = 100% — обязательное условие, дальше слои качества.

**L2 — стилометрия** (авто, непрерывная, пока не реализовано): Burrows's Delta по топ-150
функциональных слов, LUAR-косинус, burstiness (σ/μ длин предложений), TTR. Каждая метрика —
z-скор против распределения реальных held-out отрывков *между собой*: потолок — «настолько же
близко, насколько одна реальная заметка близка к другим», не ноль.

**L3 — судья** (попарно, вслепую, с якорями): кандидат A против B + 3 реальных held-out
отрывка как якорь. Вопрос: «который правдоподобнее написан тем же автором, что и якоря?»
Оба порядка подачи; расхождение = ничья. Панель из 3 судей разных модельных семей,
большинство. Судья ≠ генератор.

## Порог засчитывания улучшения

Все три одновременно:
1. ≥14/20 order-consistent побед в L3 (биномиальный p≈0.058); ≥15/20 — уверенно (p=0.021).
   Ничьи против кандидата.
2. L1 = 100%.
3. Ни одна L2-метрика не просела больше 0.5 SD.

## HELD-OUT-A (требует владельца корпуса — не делать автоматически)

Из корпуса заметок заморозить 40 реальных отрывков по 150–400 слов, стратифицированно по
формату (пост / сценарий / дневник / ответ) и эпохе (2013–19, 2020–23, 2024–26).
Правила:
- Ничего из HELD-OUT-A не попадает в SKILL.md nikolai-voice; текущие Образцы 1–4 заменить
  отрывками из отдельного CALIB-пула.
- Зафиксировать `heldout.sha256`.
- Промпт eval-0 («11 тысяч заметок за 17 лет») контаминирован темой Образца 1 — заменить.
- Айтемов 20: из каждого отрывка извлечь *ситуацию* (тема + формат + дата), текст выбросить,
  промпт писать по ситуации; реальный отрывок — скрытый reference. 5 айтемов адверсарные
  (темы, провоцирующие мотивационный регистр).

## Человеческая калибровка (~25 мин на итерацию)

Слепой forced-choice, 20 пар «реальный отрывок против сгенерированного»: «который написал я?»
≤13/20 верных (p>0.13) — подделку уже не отличить. Плюс Cohen's κ между панелью L3 и своими
метками: κ<0.4 — чинить судью раньше, чем ему доверять (feedback.json итерации-1 доказал,
что шаг не опциональный: автооценка 1.0 при человеческом «отстой полный»).

## Анти-оверфит

- Ротировать 5 из 20 айтемов каждую итерацию из нетронутого резерва.
- Никогда не править рубрику под конкретный провал.
- Логировать L1/L2/L3 каждой итерации в CSV рядом с этим файлом.
